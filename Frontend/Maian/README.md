## Descripción / Description / 简介

MaiAn Frontend es una aplicación **Kotlin Multiplatform** que usa **Compose Multiplatform** para compartir la interfaz de usuario entre Android, iOS, Desktop (JVM) y Web (Kotlin/Wasm).  
MaiAn Frontend is a **Kotlin Multiplatform** app using **Compose Multiplatform** to share UI across Android, iOS, Desktop (JVM), and Web (Kotlin/Wasm).  
MaiAn 前端基于 **Kotlin Multiplatform** 与 **Compose Multiplatform**，支持 Android、iOS、Desktop（JVM）和 Web（Kotlin/Wasm）四端共享 UI。

## Módulos / Modules / 模块结构

| Módulo | Descripción |
|---|---|
| `shared` | Base común: cliente HTTP (Ktor), repositorios, tema visual, i18n, componentes reutilizables, almacenamiento de tokens |
| `standard` | Aplicación cliente para minoristas (login, registro, pantalla principal) |
| `enterprise` | Aplicación para mayoristas — módulo más maduro; gestión de categorías y productos |
| `admin` | Panel de administración (login, categorías, usuarios) |
| `business` | Capa de negocio reutilizable: formularios de categoría, editor de texto enriquecido, gestor de medios |
| `iosApp` | Punto de entrada iOS (SwiftUI wrapper) |
